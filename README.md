# 🏗️ Computer Programming in Civil Engineering (CPCE - SPPU)

This repository contains Python-based assignments for CPCE (BE Civil - SPPU), focused on solving real-world civil engineering problems using programming.


## 🎯 Objective
To apply Python programming for solving civil engineering problems and develop computational thinking, analytical skills, and problem-solving ability.


## 📚 Topics Covered
- Python basics (loops, conditions, functions)
- Data structures (lists, tuples, dictionaries)
- Numerical computations
- Engineering problem solving
- Basic data visualization


## 📌 Completed Assignments

1. **Open Channel Flow** – Channel analysis (rectangular, triangular, trapezoidal sections)
2. **Hydrology** – Infiltration capacity and indices
3. **Transportation Engineering** – PCC pavement design for two-lane highway
4. **Concrete Technology** – Concrete mix design and strength (IS 10262:2019)
5. **Structural Engineering** – One-way slab design (steel reinforcement calculation)
6. **Structural Engineering** – Pin-jointed truss analysis (method of sections)
7. **Solid Waste Engineering** – Settling velocity of suspended solids
8. **Environmental Engineering** – Residual chlorine calculation in water
9. **Foundation Engineering** – Soil shear strength analysis


## 🛠️ Tech Stack
- Python 3.x
- NumPy / Pandas (where applicable)
- Matplotlib (for visualization)

This repository is part of academic coursework under **Savitribai Phule Pune University (SPPU)** and is intended for educational and learning purposes only.
